# Results

Only **new, independently run experiments** should be recorded here. The public repository does not claim an accuracy or Kaggle leaderboard score derived from the refactored code without a run on the official data.

`train.py` writes fresh `outputs/validation_metrics.csv` and `outputs/run_info.json` when the competition data has been downloaded. The `outputs/` folder is ignored by Git.

Historical notebook outputs and their evaluation limitations are described in `docs/technical_notes.md`.
